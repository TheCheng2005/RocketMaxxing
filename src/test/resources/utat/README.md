Input files of the UTAT Rocketry load calculation (Load_calculations.py) for the Discovery rocket, from
https://github.com/ArthurJWH/UTAT-Rocketry (Load_calculations/, commit e4d52d2). Script by Fred Chun (2021), edited by
Nat Espinosa (2023), Alexander Boldis (2024) and Nadim Hatoum (2025, 2026). Used by LoadDiagramsTest to check that the
app's implementation gives the script's numbers on the script's own inputs.
